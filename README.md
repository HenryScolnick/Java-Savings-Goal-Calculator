# Java Savings Goal Calculator

## Overview
A beginner Java program that calculates how many years it takes for an initial deposit to reach a target account balance using annual interest.

I created this project to apply my developing Java skills to a financial concept and explore how interest rates affect savings goals.

## Features
- Accepts an initial deposit.
- Accepts an annual interest rate.
- Allows the user to set a target balance.
- Calculates account growth year by year.
- Displays the number of years needed to reach the goal.
- Displays the final account balance and total growth.
- Checks for invalid inputs and a zero interest rate.

## Java Concepts Used
- Variables and data types
- Scanner and user input
- Arithmetic operations
- If/else statements
- While loops

## How to Run
1. Install a Java Development Kit (JDK).
2. Download `Main.java`.
3. Open a terminal in the folder containing the file.
4. Compile using `javac Main.java`.
5. Run using `java Main`.
6. Enter the requested information.

## What I Learned
This project helped me practice loops, conditional statements, and arithmetic while applying Java to a practical financial problem.

## Disclaimer
This calculator is for educational purposes. It assumes a constant annual interest rate and does not account for taxes, fees, or additional deposits and withdrawals. Actual investment returns are not guaranteed.
